# Workout Editor Help

This screen helps you build or update one workout in your routine. Everything below is explained in the same order it appears on the screen.

## Add Cover Media

Tap the large media area at the top to choose a GIF for this workout.

Purpose:
- This gives the workout a visual reference.
- The GIF can appear in your routine list and during playback.
- If a workout already has media, tapping the same area lets you replace it.

## Workout Name

The workout name box is where you type the name you want Semaphore to show for this workout.

Purpose:
- This is the label you will see in your routine.
- This is also the name Semaphore can speak out loud when the workout begins.

## Speaker Icon In The Workout Name Box

The speaker icon turns spoken workout names on or off for this specific workout.

Purpose:
- When it is on, Semaphore will use text to speech to say the workout name when that workout starts.
- When it is off, the workout will stay silent.
- Tapping the icon opens a confirmation message before changing the setting.

## Duration

The duration section is where you set how long this workout lasts.

Purpose:
- `HR` sets the number of hours.
- `MIN` sets the number of minutes.
- `SEC` sets the number of seconds.
- The `Target` badge is a visual label that tells you this section controls the workout length.

## Save Workout

The save button at the bottom stores your changes.

Purpose:
- On a new workout, it creates the workout and adds it to your routine.
- On an existing workout, it updates the workout with your latest changes.

## Back Button

The back button in the top left leaves this screen.

Purpose:
- It returns to your routine without saving new edits from this visit unless you already tapped `Save Workout`.

## Help Button

The question mark button in the top right opens this help screen.

Purpose:
- It explains every major control on the workout editor.
- It can be used any time you need a quick reminder of what a button or input does.

## Accessibility Notes

- If you use a screen reader, this page is meant to describe the editor in a predictable top-to-bottom order.
- If spoken workout names are enabled, Semaphore can announce the name you entered when the workout begins.
- The media area is optional, but the workout name and duration are important for creating a usable workout.
